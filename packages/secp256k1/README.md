# @frosts/secp256k1

> **Disclaimer:** This project is in early development stages and has **not been audited**. Use for testing purposes only.

FROST(secp256k1, SHA-256) - A Schnorr signature scheme over the secp256k1 curve that supports FROST threshold signatures.

This package is a re-export of the ciphersuite-generic [@frosts/core](https://www.npmjs.com/package/@frosts/core) package, parametrized with the secp256k1 curve. For more details, refer to [The ZF FROST Book](https://frost.zfnd.org/).
