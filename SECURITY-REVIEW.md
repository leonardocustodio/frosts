# Security Review

This project has **not yet received a formal security review**.

frosTS is a TypeScript port of [ZcashFoundation/frost](https://github.com/ZcashFoundation/frost), which has been audited. However, this port is an independent implementation and should be treated as unaudited until reviewed.

For production use, we recommend the audited [Rust](https://github.com/ZcashFoundation/frost) implementation.

To fund a security review, contact us at security@snowpine.io
